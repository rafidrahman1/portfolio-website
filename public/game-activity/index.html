Game Activity Upload

A personal tool by Rafid Rahman

Game Activity Upload is a small script that runs on my own Windows PC. It exports my game play history (game name, session date and time played) from Playnite to a CSV file and uploads that file to my own Google Drive.

It uses Google's drive.file permission, so it can only see and change files and folders it created itself. It cannot read anything else in your Drive.

The app is not offered as a service to other people.
