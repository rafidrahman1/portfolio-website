Privacy Policy

Game Activity Upload · Last updated 25 November 2026

What the app does

Game Activity Upload runs only on the user's own computer. It reads game play history (game name, session date and time played) stored locally by Playnite, saves it as a CSV file and uploads that file to the user's own Google Drive.

Google user data it accesses

The app asks for one permission: https://www.googleapis.com/auth/drive.file. With it, the app can only create and update the files and folders that it created itself (a folder and a CSV file). It cannot see, read or change any other file in the user's Google Drive.

How data is used and stored

  • The CSV file goes straight from the user's computer to the user's own Google Drive. It is not sent to any other server.
  • Google sign-in tokens are stored only on the user's computer, encrypted with Windows DPAPI so that only that Windows account can read them.
  • No data is collected, stored, sold or shared with the developer or with any third party.
  • The app has no analytics, tracking or advertising.

Google API Services User Data Policy

Game Activity Upload's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can remove the app's access at any time at myaccount.google.com/permissions. Deleting the files it created from Google Drive removes all data it uploaded.
